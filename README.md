# Герои III — подготовка к партии

Подготовка к партии в настольной игре «Герои Меча и Магии III» издательства Archon Studio: выбрать сценарий, собрать колоды и жетоны и найти правило.

Откройте `index.html`.

## Миссии

`missions.html` собирает сценарий из книги миссий.

- Фильтр списка миссий по режиму, дополнению и тем допмеханикам, которые есть не в каждом сценарии: события Крепости и усиленные навыки. Отмеченное оставляет миссии, где это возможно. Галочки внутри миссии включают механику уже в выбранную партию. Состав колоды и жетонов открывается кнопкой «Состав».
- Отметка, какие коробки есть дома: от неё зависят общие колоды и доступные модули.
- У выбранной миссии два списка. Обязательные механики сценарий включает всегда. «По выбору» — модули коробок и дополнительные правила; их отмечают уже внутри миссии.
- «Что выложить» перечисляет тайлы, жетоны, колоды и стороны игроков. Код тайла открывает страницу гида по содержимому коробки.

## Памятка

`rules.html` — правила и колоды.

- Сетка механик по режимам: есть, нет, по желанию или только если даёт сценарий.
- Если в режиме правило другое, у отметки стоит отличие, и оно открывается отдельно.
- Название механики ведёт к тексту. «Свод, стр.» открывает эту страницу PDF.
- Раздел «Колоды карт» описывает, из чего стопка и когда её кладут.

## Локации

`locations.html` — поля фрагментов карты из книг дополнений: что поле делает и на какой странице книги это напечатано.
